# نظام إدارة الموارد البشرية

هذه النسخة تحافظ على واجهة React/Vite الحالية وتضيف خادمًا خاصًا وقاعدة PostgreSQL وتسجيل دخول حقيقيًا. تم استبدال الاتصال بخدمات Base44 بطبقة API محلية متوافقة مع استدعاءات الصفحات الحالية، لذلك تبقى وحدات الموظفين والأقسام والحضور والإجازات والأداء والمهام والرواتب والتنبيهات والمستندات والتقارير بنفس المسارات والتنسيق.

## الصلاحيات

الحساب الأول الذي يتم إنشاؤه يصبح **مديرًا** تلقائيًا. يستطيع المدير إدارة المستخدمين وتغيير دور الحساب أو تعطيله. الحسابات التالية تبدأ بدور **موظف**. الخادم نفسه يتحقق من الصلاحيات، وليس إخفاء العناصر في الواجهة فقط.

## التشغيل المحلي

يحتاج التشغيل إلى Node.js وPostgreSQL. انسخ `.env.example` إلى `.env` وعدّل `DATABASE_URL` و`JWT_SECRET`، ثم نفّذ:

```bash
pnpm install
pnpm build
pnpm start
```

يفتح النظام على `http://localhost:3000`. عند أول تشغيل، ينشئ الخادم الجداول تلقائيًا من `server/schema.sql`. افتح `/register` لإنشاء حساب المدير الأول.

## النشر على Railway

أنشئ مشروعًا جديدًا في Railway، ثم أضف خدمة PostgreSQL وخدمة التطبيق. اربط خدمة التطبيق بمستودع GitHub بعد رفع هذا المجلد، وسيستخدم Railway إعدادات `railway.toml`. أضف متغيري البيئة `DATABASE_URL` و`JWT_SECRET`. لا ترفع ملف `.env` إلى GitHub.

## رفع المشروع إلى GitHub

بعد إنشاء حساب GitHub ومستودع خاص، نفّذ من مجلد المشروع:

```bash
git init
git add .
git commit -m "Migrate HR system to private PostgreSQL backend"
git branch -M main
git remote add origin https://github.com/YOUR_ACCOUNT/YOUR_REPOSITORY.git
git push -u origin main
```

اجعل المستودع **Private** إذا كانت بيانات النظام أو الشفرة خاصة.

## ملاحظات مهمة

الملفات المرفوعة تُخزّن حاليًا داخل جدول PostgreSQL بصيغة binary حتى لا تعتمد النسخة على تخزين خارجي. يفضّل تفعيل النسخ الاحتياطي الدوري لقاعدة Railway قبل الاستخدام الفعلي. لم يتم ترحيل بيانات Base44 تلقائيًا؛ النسخة تبدأ بقاعدة جديدة، ويمكن إضافة ترحيل منظم عند توفير تصدير البيانات.
